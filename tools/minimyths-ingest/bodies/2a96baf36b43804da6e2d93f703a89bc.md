# Come get some awesome photos!

With [Armies on Parade off the table for 2025](https://mini-myths.com/blog-posts/armies-on-parade-2025), we want to make sure we take the time to capture all your amazing miniature projects from the year.

If you've got an awesome project that you'd love to get some photos of, please consider grabbing a ticket for this **Photo Day!** I'll be at Guf Werribee all day taking snaps of people's models, and I'd love to add yours to the queue!

To make like easier for me, and to raise a little bit of cash for the club, we've created a few packages for you to pickup. Think of it a little like school photos! Grab the package that fits what you're after/your budget, and then simply come on down and hang with me while we capture some sweet snaps of your toy soldiers.

Curious about our photos? Checkout the Photos page here!

# Packages
### Package 1 - Just a Lil' Guy
This package is perfect if you've just got a couple miniatures you'd like to get some snaps of. These miniatures can be of any size - whether it's 3 grots, or 3 baneblades - this package works for you!
We'll get some sweet lightbox pics of each miniature, and then some cool scenic shots too.
<bookmark source="https://ko-fi.com/s/17bd6386f3" />

### Package 2 - A Few Buddies
This is our 'squad' package - if you've got a squad (or two smaller squads), pick this package. As long as it's under the 15 miniature count, feel free to throw in a few individual models too. Much like the first package, size doesn't matter (although I swear to god, if you bring my 15 Thunderhawks, we're going to have a discussion).
We'll get some sweet lightbox pics of each miniature, and then some cool scenic shots too.
<bookmark source="https://ko-fi.com/s/aad5fd7f9a" />

### Package 3 - The Whole Fam
This is the army package. Bring whatever you've got and we'll do whatever we can in an hour. Bring one miniature and we'll capture every angle, or bring 100 miniatures and we'll get some awesome army shots. Totally up to you - anything you want, we'll do as much as we can in 60 minutes.
Depending on how much you bring, we'll try and get everything in the lightbox and get some scenic shots too - but it's up to what you how we spend the time!
